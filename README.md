# AI OCR Code Typer

Windows 截图或手动复制获取题目、AI 生成代码与按键逐字输入工具（CodePilot）。

A Windows AI coding assistant with screenshot OCR or clipboard text input, DeepSeek code generation, and key-triggered character-by-character typing.

支持 Windows 10/11，需要可用的 AI API Key 和网络连接。

## 从源码运行

安装 Python 3.12，在 PowerShell 中执行：

```powershell
git clone https://github.com/makealivi/ai-ocr-code-typer.git
cd ai-ocr-code-typer
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

程序会打开配置网页。填写 API Key，选择语言并点击 **保存全部配置**，然后按照下方步骤使用。

## 构建 Windows 程序

完成上述依赖安装后，在项目目录执行：

```powershell
.\.venv\Scripts\python.exe -m pip install pyinstaller
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

构建结果位于 `release/启动/`。分发时保留整个目录。

## 功能

- 按快捷键静默截取全屏，在本机 OCR 识别题目后请求 DeepSeek 生成代码，完整结果写入剪贴板。
- 手动选中题目并右键复制，再按剪贴板快捷键，直接用复制的文字生成代码；与截图入口共用语言、API Key 和模型配置。
- 每次按下 A–Z（大小写均可）或 `[];',./` 中任一键，输出代码的下一个字符，原按键不会输入编辑器。
- 网页可配置多套截图及剪贴板快捷键、编程语言、API Key、API 地址和模型，运行过程不弹窗。
- 可选择在 Windows 底栏右侧显示微信样式托盘图标，代码可以逐字输入时，图标本身闪烁。
- 生成指令区分函数题与完整程序题。

## 使用方式

1. 从源码启动程序，或在构建后双击 `release/启动/启动.exe`，在网页填写 API Key，选择语言并点击 **保存全部配置**。API 地址默认为 `https://api.deepseek.com`，模型默认为 `deepseek-flash`。
2. 打开题目网页，按 **F1** 截取全屏；也可手动拖选题目正文，通过右键菜单复制，再按 **F2** 读取剪贴板。等待网页显示 **可以逐字输入**；启用托盘图标后，也可通过图标闪烁查看就绪提示。
3. 切换到编辑器，按 A–Z 或 `[];',./` 逐字输出代码。
4. **F8** 暂停／恢复，暂停后可正常打字；**F9** 结束本轮，后台继续运行，已输入的文字和剪贴板代码保留。
5. 关闭网页后快捷键仍生效；再次双击启动文件可重开网页，点击 **退出程序** 关闭后台。

连续按键时，暂停或结束本轮会取消尚未开始输出的字符；已经开始发送的一个字符仍可能完成。恢复输入后，从下一个未发送字符继续。

字符发送失败时，程序会暂停输入并在网页显示错误。按提示处理后，按 **F8** 从失败的字符继续。

## 查看托盘提示

在配置页侧栏勾选 **显示微信样式托盘图标**，点击 **保存全部配置** 后，底栏右侧显示 CodePilot 图标。该选项默认关闭；取消勾选并保存后立即隐藏图标，重启后保留选择。

启用后，关闭配置网页仍会提示代码就绪。图标只显示微信外观，没有数字角标或红点。代码就绪时图标闪烁，首次成功输入字符或单击图标后停止闪烁。暂停输入会停止闪烁，恢复后继续尚未确认的提示；结束本轮或开始新一轮会清除上一轮提示。

隐藏图标后，仍可使用快捷键逐字输入代码。同一轮代码尚未确认就绪提示、且输入未暂停时，重新显示图标会继续闪烁。

右键图标可选择 **打开配置**、**暂停输入／恢复输入**、**结束本轮** 或 **退出程序**。悬停图标可查看 CodePilot 当前状态。

开启显示微信样式托盘图标选项后，请将图标固定到底栏可见区。图标收在底栏的 **∧** 隐藏区时，将它拖到底栏右侧即可常驻显示。图标使用微信外观，悬停名称为 **CodePilot**。

## 生成函数题代码

生成指令要求函数题只返回所需函数和必要辅助定义，不重复题目已提供的类型、裁判程序或 `main`；完整编程题返回完整程序。截图或复制的题目应包含函数接口及题目提供的类型定义。

## 注意事项

- 由于编辑器会自动补 `}`，使用自动打字输入代码后，结尾会多几个 `}`，请注意手动删除。也可提前关闭编辑器的括号补全。
- 请关闭编辑器的自动缩进和自动格式化，使用英文输入模式，保持程序与编辑器的权限级别一致。
- 全屏截图包含全部显示器当时可见的内容，不会自动滚动网页；识别文字会发送到所配置的 API。
- 剪贴板入口读取你已复制的文字，保留换行与缩进。请复制完整题目，包含接口、约束和样例；图片中的文字仍需使用截图入口。复制的文字会发送到所配置的 API，生成完成后剪贴板会替换为代码。
- **剪贴板生成快捷键** 默认 F2。旧配置升级时若 F2 已被其他操作使用，会从 F2–F24 中分配下一个空闲功能键，跳过 Windows 保留的 F12；没有可用键时保持关闭。新增方案也会跳过 F12。留空并保存可关闭此入口。每轮开始前请重新复制题目。
- 若提示剪贴板中没有文字，请先手动选中题目并右键复制，再按剪贴板生成快捷键。
- 更新源码后，先在配置页点击 **退出程序**，再重新启动。关闭网页或再次双击启动文件只会重开网页，不会更新仍在运行的后台。
- 每次实际按下触发键仅输出一个字符，长按不会连续输出；Ctrl、Alt、Win 组合键保留原功能。
- 快捷键修改后需保存；接口或识别失败时，在网页查看错误并按提示处理。
- 支持 Windows 10/11；使用时保留启动文件所在的整个文件夹。API Key 保存在当前 Windows 用户的凭据管理器中。
